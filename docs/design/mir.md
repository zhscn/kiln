# MIR：Rust 语义中端

MIR（mid-level IR）由 Rust 从已解析的 HIR 构造，采用控制流图和标量 SSA。它负责 Lisp 程序的分析、优化和表示选择，输出 KIR。MIR 尚未实现；现有对应能力仍在 Lisp HIR 分析和降级代码中。

## 数据模型

模块、函数、基本块、指令和值使用有类型的紧凑 ID 和 arena 存储。基本块参数表达 SSA 合流，终结指令列出全部后继和边参数。绑定 ID、源码身份、声明策略与生成的 SSA 值 ID 分开；循环中的一个静态分配点不代表所有动态对象具有同一身份。

标量 SSA 描述计算结果；可变堆字段、闭包共享 cell、全局函数格和动态环境保留显式操作。初期不要求完整 Memory SSA。分析结果保存在侧表，按函数修订号标识有效性；修改 CFG、调用或存储的 pass 必须声明失效的分析，不能沿用旧证明。

语义类型与机器表示分离。一个值可以具有整数区间事实，同时仍使用装箱表示。literal ID 引用请求持有的常量，不是 Rust 可以解引用的 Lisp 地址。

## 抽象操作与控制流

MIR 保留 cons、闭包、捕获 cell、数组访问、函数调用、多值和动态环境操作。对象偏移、tag、栈槽及 context 字段在表示和 ABI 降级时引入。

已知局部调用引用函数 ID。全局调用默认读取可重定义的函数格；只有语言保证、依赖或守卫支持时才能直接调用或内联。闭包组保留相互递归和共享可写捕获，存储选择不能复制本应共享的 cell。

多值采用显式 bundle，包含值数及可投影的值。主值消费、全部值转发、保存和恢复分别表达；固定数量多值可以拆成 SSA 值，未知数量仍保留 bundle。直到 KIR 降级才映射为主返回值、计数和 `ctx.values`。

可能退出的调用具有正常边和退出边，结果只在正常边可用。本地 `go` 和 `return-from` 转成控制流边；跨函数退出、动态 catch 和清理区域仍显式存在。每条离开动态范围的路径必须执行正确的恢复与 cleanup；cleanup 自身的退出覆盖原退出。捕获的退出目标使用具备动态有效期的身份，不保存可被重用的栈地址。

## 效果与分析

效果摘要分别记录堆与全局读写、动态环境访问、分配、GC、可能退出和未知调用。结果未使用不能证明操作可删除；分配消除还必须证明身份、错误和调试可观察行为保持成立。

Rust 中端承担以下分析：

- 可达性、支配关系、use-def、循环和调用图；递归组按 SCC 求解摘要。
- 类型与整数区间传播，固定点迭代、widening 和发布前的后验验证。预算耗尽时回退到保守事实。
- 局部调用身份、参数及多值返回摘要、按策略和增长预算控制的内联。
- 别名、对象包含关系、捕获和逃逸，及闭包、cons、rest 列表的存储选择。
- 装箱消除、浮点和整数机器值、运行期检查及显式慢路径。

不透明类型、未知调用和动态退出扩大效果及逃逸集合。更精细的类与布局事实通过带版本的描述输入；优化 pass 不回调 Lisp 环境。活 image 的推测使用显式守卫及普通调用回退，定义发布前验证依赖；seal 后才使用冻结世界的更强证明。

## 身份与存储证明

标量替换要求对象身份不可观察，字段别名和写入已经纳入分析。保留身份的栈存储要求对象及其可到达引用不越过帧或动态有效期；未知调用、返回、全局存储、堆容器和捕获均可能产生逃逸。

循环重入、对象比较、可变字段和调试器观察必须参与证明。不能把每次迭代的新对象都放入同一地址并让多个身份同时存活。rest 尾部、对象字段与闭包捕获需要传递逃逸，不能只检查直接使用点。堆对象不得保存未经 runtime 支持的栈内指针。

栈对象的引用字段仍需精确 roots；机器值不得登记为对象引用。存储选择必须满足移动 GC、poll 点、非局部退出与调试变量访问约束。无法证明时保留堆分配和装箱路径，`dynamic-extent` 也须遵守其语言契约。

## 验证与降级

导入、结构变换后及 KIR 降级前运行分层验证：检查 ID、SSA 支配、边参数、终结指令、捕获关系、多值协议、动态区域、调用签名及策略来源。输入错误返回结构化诊断；内部不变量失败报告编译器错误，不发布部分代码。

表示降级选择对象、raw 整数和浮点寄存器，安排闭包与 cell 布局、分配、写屏障、poll、GC roots 和调试描述。布局与调用约定来自 runtime 的目标描述和 ABI 指纹。内部调用约定的特化需要显式入口协议；初期维持现有 Lisp ABI。

KIR 的内部 Rust 数据结构直接交给 kiln-cg，文本仍用于文件、诊断、FASL 和确定性比对。Cranelift 负责机器 SSA、低级优化和寄存器分配。具体阶段见 [降级](lowering.md)。
